# KalaKart - Local Art. Global Reach.
## Structure
src/config (db) | src/models (User, Product, Order) | src/routes (auth, products, seller, orders, admin) | src/utils.js (auth, validation) | src/app.js | src/server.js | public (index.html, style.css, app.js) | docs
## Run
1. Node 20.6+ and a free MongoDB Atlas database
2. cp .env.example .env and fill it in
3. npm install
4. npm start -> http://localhost:5000
